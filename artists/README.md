# TBN 艺人单屏入口网页

单页静态网站，使用原生 HTML、CSS 和 JavaScript，无需安装依赖。

## 打开方式

直接双击 `index.html` 即可预览。也可以用任意本地静态服务器打开本目录。

## 内容维护

- 艺人资料和个人主页地址：`script.js` 顶部的 `artists` 数组
- 现役艺人名单：19 位，来自 `/Users/hjay/Documents/2026/艺人/1 完成/艺人海报`
- 海报图片：`assets/posters/roster-20260916-*`
- 视觉与响应式布局：`styles.css`

网站只有一个全屏艺人入口：当前海报完整展开，两侧海报半幅裁切，切换艺人时背景色调和资料同步变化。页面打开后会自然入场并自动轮播；鼠标滚轮、触控板、拖动和键盘方向键都可以切换艺人。

点击两侧海报会先把该艺人平滑移动到中央；再次点击中央完整海报，或点击右上角的艺人名称与 `VIEW WEBSITE`，即可进入个人主页。每位艺人的 `website` 为空时会显示“网站正在建立中 / COMING SOON”；未来把完整主页地址填入对应的 `website`，点击后就会直接进入该艺人主页。
